# MacroSnap - AI Nutrition & Macro Tracker

MacroSnap is an AI-driven nutrition tracker that allows users to snap a photo of their meal or describe it in natural text to get real-time calories and macronutrient breakdowns. It also exports a full daily recap directly to WhatsApp.
